# agrinho-2026 

Este projeto foi desenvolvido especialmente para o concurso Agrinho 2026, trazendo como tema central "Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente".

A proposta consiste em uma página web interativa e responsiva que utiliza uma identidade visual inspirada nas cores do campo: o verde da preservação, o amarelo da força produtiva e o branco que simboliza o equilíbrio entre ambos.

Destaques do projeto:

Interface Temática: Design focado na imersão do usuário com paisagens rurais e componentes visuais modernos.

Interatividade com JavaScript: Sistema de filtros dinâmicos que permite ao usuário alternar a visualização entre práticas de alta produtividade (Agro Forte), ações ecológicas (Sustentabilidade) ou a união de ambas (Equilíbrio Perfeito).

Animações Fluidas: Efeitos de carregamento suave (fade-in) nos blocos de conteúdo, melhorando a experiência de navegação.
